# 🚗 Car Sales Data Analysis (Excel + Power Query)

## 📊 Project Overview
This project analyzes car sales data to identify trends in revenue, pricing, and market performance across multiple years.

## 🧠 Business Problem
Analyze sales data to uncover insights on top brands, regions, and pricing strategies.

## 🧹 Data Cleaning
- Cleaned using Power Query
- Removed missing values
- Created Year & Month columns

## 📈 Analysis
- Revenue trends
- Brand comparison
- State performance
- MMR vs Selling Price
- Vehicle condition impact

## 📊 Dashboard
Interactive Excel dashboard with KPIs and slicers.

## 📌 Key Insights
- Revenue is growing year-over-year
- Top brands dominate market share
- SUVs and sedans generate highest revenue
